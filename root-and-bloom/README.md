# Active Root & Bloom Application

This folder contains the active React/Vite storefront and its private Express backend.

## Run

```bash
npm install
npm run dev
```

The storefront runs on `http://127.0.0.1:3000`; the private backend runs on `127.0.0.1:3001`.

See the repository-root [README](../README.md), [architecture](../architecture.md), and [implementation guide](../implementation.md).
